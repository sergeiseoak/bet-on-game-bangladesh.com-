# Bet on Game Bangladesh

Static HTML website ready for Cloudflare Pages.

## Deployment
Upload the contents of this ZIP to the root of a GitHub repository, connect the repository in Cloudflare Pages, choose framework preset **None**, leave build command blank and set output directory to `/` (or use Direct Upload of the extracted folder).

The `/go/` route redirects to the provided affiliate URL.

Six content pages, responsive styles, robots.txt, sitemap.xml, canonical, OG and GSC verification included.
